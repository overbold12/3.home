# 대출조건 입력 개발 메모

참조: [대출조건 설정(TO-BE), Figma 335:4960](https://www.figma.com/design/VOdc8ksUmREL5maAgtbAxl?node-id=335-4960)

현재 범위: 프레임 표시, 신청 금액·기간·상환방식 변경, 상환방식 안내 바텀시트, 자동 보정 및 납입금액 계산, 로딩과 화면 펼침.

최초 심사결과: 3,000만원 / 11.45% / 120개월. 최초 상환방식은 원리금균등이다. 첫 달 예상 납입금액은 실제 계산값인 420,929원으로 표시한다(디자인의 360,541원은 예시 값).

적용한 사용자 지정 로직:

| 대출 기간 | 기간별 최대한도 | 적용금리 |
| --- | --- | --- |
| 12~60개월 | 1,000만원 | 10.56% |
| 72~120개월 | 3,000만원 | 11.45% |

- 대출 기간을 변경하면 기간별 최대한도와 적용금리도 변경한다.
- 신청금액이 1,000만원 **미만**이면 대출 기간은 최대 60개월까지만 지정할 수 있다.
- 신청 금액 바텀시트는 금액 단위가 만원이며, 최소한도는 100만원, 최대한도는 현재 기간별 한도다. 엔터를 누르면 입력값을 범위 내 정수로 보정해 입력칸에 표시하고, 완료 버튼으로 조건에 반영한다. 완료 버튼도 동일한 보정을 적용한다.
- 기간은 12개월부터 120개월까지 12개월 간격으로 선택한다. 1,000만원 미만일 때 72~120개월은 비활성화한다. 정확히 1,000만원이면 120개월까지 가능하다.
- 금액을 낮춰 기간이 범위를 벗어나면 최대 60개월로 보정한다. 기간을 낮춰 신청금액이 한도를 초과하면 해당 기간의 최대한도로 보정한다.
- 원리금균등: `원금 × 월금리 ÷ (1 − (1 + 월금리)^(-개월 수))`.
- 원금균등 첫 달: `원금 ÷ 개월 수 + 원금 × 월금리`.
- 월금리는 연금리 ÷ 12, 납입금액은 원 단위 반올림한다. 실제 일수·실행일·수수료를 반영하는 기능은 요청 범위에 포함되지 않는다.
- 조건 확정 후 650ms 동안 제공된 `LoadingSpinner.png`를 표시하고, 결과를 갱신하며 화면 상단으로 돌아와 펼침 효과를 표시한다.
- 바텀시트 외부 터치와 Escape로 닫을 경우 미확정 입력은 반영하지 않는다.
