# 대출조건 입력 개발 메모

참조: [대출조건 설정(TO-BE), Figma 335:4960](https://www.figma.com/design/VOdc8ksUmREL5maAgtbAxl?node-id=335-4960)

현재 범위: 프레임 배치와 최초 심사결과 표시. 신청 금액, 대출 기간, 상환방식 변경 기능은 추후 요청 시 구현한다.

최초 심사결과: 3,000만원 / 11.45% / 120개월. 프레임의 최초 상환방식은 원리금균등이며, 첫 달 예상 납입금액 360,541원은 디자인의 표시값을 유지한다.

추후 변경 기능을 구현할 때 적용할 사용자 지정 로직:

| 대출 기간 | 기간별 최대한도 | 적용금리 |
| --- | --- | --- |
| 12~60개월 | 1,000만원 | 10.56% |
| 72~120개월 | 3,000만원 | 11.45% |

- 대출 기간을 변경하면 기간별 최대한도와 적용금리도 변경한다.
- 신청금액이 1,000만원 **미만**이면 대출 기간은 최대 60개월까지만 지정할 수 있다.
- 상환방식 변경 기능 구현 시에도 위 조건을 함께 고려한다. 상환방식별 추가 규칙은 아직 지정되지 않았다.
